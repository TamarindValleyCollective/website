# Change Log — October 2026

One line per change: date, title, requester, the *intent* behind the ask (not a verbatim
quote), what actually changed, and the commit hash(es). Newest at the top. See `CHANGELOG.md`
for the format note and index of other months.

- **2026-10-04** Smooth the cumulative rainfall line (Sharath) — rain days read as vertical steps at
  the chart's scale; the line is now drawn from a 7-day centered moving average (exact start and end
  totals; tooltip and end-dot keep the real total). `70ef7fb`
- **2026-10-04** Clear the lint backlog of raw hex colors (Sharath) — after adding the design-language
  Stylelint check, replaced token-matching and stray hex values with tokens, defined `--tvc-white` and
  swapped ~110 literal `#fff`, and annotated the remaining non-TVC colors with disable comments
  (143 → 16 warnings, all in WeatherView). `66aa10c`, `9456388`
- **2026-10-04** Enforce the design language with Stylelint and CI (Sharath) — so anyone with repo
  access uses the same tokens; added a Design language section to AGENTS.md, a Stylelint config
  (errors on undefined custom properties, warns on raw hex and radius literals), `npm run lint:css`,
  and a `Design language` PR check. `c483dae`, `72476fc`
- **2026-10-04** Align the site with its design tokens (Sharath) — after extracting a design
  system from the codebase, an audit found components using undefined tokens and off-palette
  oranges; defined `--tvc-orange-strong`/`--tvc-ink-faint`/`--tvc-surface`, added
  `--tvc-orange-light` (footer hovers were 2.66:1 on green) and `--radius-sm`/`--radius-field`, and
  moved small orange text to `--tvc-orange-text`. `22e9316`
- **2026-10-02** Keep the "rainfall so far this year" stat showing at the start of a month
  (Sharath) — tile went blank on 1 Oct because no October day was logged yet; now falls back to
  the end of the latest logged month (e.g. "1 Jan – 30 Sep") and the chart stops there too. `1fb15a8`
- **2026-10-01** Tally Razorpay fees by payment method and track settlements on the
  event-payments dashboard (Sharath) — TVC absorbs MDR rather than passing it on, so the
  dashboard needed a real record of what each payment method costs. It now has a Money breakdown
  (MDR vs GST, fees on refunded bookings, net to TVC, settled to bank) and a fees-by-method
  table. The nightly reconcile script stopped double-counting GST and gained a settlement pass
  (migration `0027`); the one live payment is backfilled. There's also a dev-only `?demo` mode, which the two process docs'
  new screenshots were taken from. `a3dfdda` `b60c42c` `87c7a14` (merged in `3c212e7`)
