One line per change: date, title, requester, the *intent* behind the ask (not a verbatim
quote), what actually changed, and the commit hash(es). Newest at the top. See `CHANGELOG.md`
for the format note and index of other months.

- **2026-09-20** Fix the trailing-slash bug that silently defeated both breadcrumb fixes below
  (Sharath) — reported `/our-journey` still showing the old marketing title after the nav-label
  fix shipped; traced it to `Astro.url.pathname` always carrying a trailing slash in the static
  build (`/people/`) while `site-map.ts` hrefs never do, so both `navKeyFor`'s exact match and
  the events self-reference check never actually fired post-deploy - `sectionFor`'s prefix
  matching happened to tolerate the mismatch, which is why the section-level crumb looked fine
  and masked the regression. `Breadcrumbs.astro` now strips the trailing slash once before any
  comparison. Rebuilt and redeployed to production directly since deploys here aren't wired to
  auto-build from GitHub pushes.
