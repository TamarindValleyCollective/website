# Change Log — September 2026

One line per change: date, title, requester, the *intent* behind the ask (not a verbatim
quote), what actually changed, and the commit hash(es). Newest at the top. See `CHANGELOG.md`
for the format note and index of other months.

- **2026-09-07** Polish the "Add to calendar" button's design (Sharath) — asked for a better look,
  and pointed at `AddEventInc/add-to-calendar-button` as a reference; declined adopting that
  library since it loads from AddEvent's own CDN with an undeclared license and phones home to
  their servers as a "centralized end-point," a third-party dependency this privacy-conscious site
  (cookie consent already in place, no trackers) shouldn't take on for a cosmetic change. Kept the
  existing dependency-free local Google-Calendar-URL/`.ics`-data-URI generation, and instead added
  a calendar icon and disclosure chevron (rotating on open) to `AddToCalendar.astro`'s toggle
  button, plus Google's own four-color mark and a calendar-download icon to the two dropdown items.
- **2026-09-07** Add a per-event "Prefer to chat first? Message {contact}" WhatsApp button to the
  events sidebar, styled like WhatsApp's own official button (Sharath) — a design critique of the
  events pages flagged the booking form's own WhatsApp CTA as buried below a long scroll, and
  discussion of its look led to building it into the always-visible "at a glance" sidebar instead,
  next to "Request to book," so a WhatsApp-first visitor doesn't have to scroll past the whole form.
  Added a `whatsapp: { number, contactName }` field to the events schema (`content.config.ts`) so
  each event can name who's actually on the other end (e.g. "Linger" for 3bs1h, "Nicole" for the
  Melagiri event, replacing that event's own hand-authored WhatsApp line in its body). Extracted a
  shared `WhatsAppButton.astro` (used by both the sidebar and `BookingInquiry.astro`'s own CTA),
  colored to match WhatsApp's official "Chat on WhatsApp" button (solid brand green, white icon)
  per their brand guidelines against recoloring their logo, but kept this site's pill button shape
  so sidebar/form buttons still read as one family. Also fixed a real bug found along the way:
  `.whatsapp-btn`'s CSS lived only in `BookingInquiry.astro`'s own bundle, so any page that never
  rendered that component (like Melagiri's, before this change) shipped its hand-authored WhatsApp
  button completely unstyled in production.
- **2026-09-07** Move the WhatsApp "prefer to chat" CTA below the booking form instead of beside it,
  then rebalance its weight after a design critique (Sharath) — wanted the form to have the full
  sidebar width instead of splitting it with a boxed WhatsApp card. `BookingInquiry.astro`'s form is
  now full-width, with "Prefer to talk first? Message us" below it. A follow-up `/impeccable
  critique` of the events pages flagged the plain-text version as visually unequal to the form's
  button (the note above it calls form and WhatsApp equal paths) and short of the mobile
  touch-target floor with the link text alone not conveying context to screen readers; restyled as
  a full outline-button link (matching the "Add to calendar" button below it) with the whole phrase
  as the accessible link text, shared by every camping/day-visit/trekking/event booking form.

- **2026-09-07** Add block/unblock control to the WhatsApp reply admin (Sharath) — asked how to
  blacklist numbers on the WhatsApp API. Added a Block/Unblock button to `/internal/whatsapp`'s

  `gemini-3.5-flash-lite`. Updated the default model.
- **2026-09-07** Add an "Ask AI" answer to site search, backed by Gemini's free tier with an

  serving `dist/` with the real generated header.
