# 3Bs&1H — frozen logo assets (v1)

Frozen 5 Sep 2026. Master file: `3Bs&1H Logo.dc.html`. Never edit these SVGs to make a
variant — duplicate instead.

## Colours
- Green (single ink, TVC brand): `#17743C`
- Cream / reversed ink: `#f2ecdb` (paper `#FBF8F1`)
- Dark ground: `#12271a`
- Annotation / secondary type: `#4d6350`
- Accent (CTA only): `#F88722`

## Type
- Wordmark `3Bs&1H` — EB Garamond, weight 500. Italic only for the small "Certificate of
  Participation" style line.
- Sublines — Archivo, uppercase, letter-spacing .22–.32em.

## Files
| File | Use |
|---|---|
| `3bs1h-quad-green.svg` | Four-creature strip, positive |
| `3bs1h-quad-cream.svg` | Four-creature strip, reversed |
| `3bs1h-bird-green.svg` | Reduced mark, positive |
| `3bs1h-bird-cream.svg` | Reduced mark, reversed |
| `tvc-mark.svg` | TVC parent mark |

## Rules
- Under 120px wide, drop the quad strip and use the bird mark alone.
- Bird mark holds down to 20px. Below that, wordmark only.
- Strokes are round-cap, round-join. Scale strokes with the artwork — never restroke.
- One ink. Do not add a second colour to the creatures.
- Clear space: half the cap-height of `3Bs&1H` on all sides.

## Sending to a printer or embroiderer
The SVGs are pure vector paths — send as-is. The wordmark is live type, so for anything
where the vendor won't have EB Garamond, ask them to outline text, or supply a PDF export
of the lockup from the master file.
